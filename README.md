# 주변 여행 도우미 (다중 파일 분리 + 기기별 API 키 보안 저장 버전)

GitHub Pages와 같은 공개 저장소에 소스 코드를 올려도 **본인의 Google Maps API 키가 외부에 절대 노출되지 않도록**, 소스 코드 내 API 키는 비워두고 **각자의 스마트폰·컴퓨터 브라우저(`localStorage`)에만 안전하게 저장**되도록 설계된 다중 파일 버전입니다.

## 📁 파일 구성 및 역할

| 파일명 | 역할 및 주요 내용 |
| :--- | :--- |
| **`index.html`** | 웹앱의 화면 뼈대(HTML 마크업)와 스타일·스크립트 연결만 담당합니다. |
| **`style.css`** | 아이폰 Safari 노치 대응, 상단 플로팅 바, 하단 시트, 장소 카드, 모달 등 모든 디자인 스타일을 담당합니다. |
| **`config.js`** | 13개 카테고리 정의, 평점/거리 우선순위, 전역 상태(`state`) 및 공통 유틸리티 함수를 담당합니다. (`GOOGLE_MAPS_API_KEY`는 보안을 위해 `""` 빈 값으로 유지) |
| **`search.js`** | 주변 카테고리 검색, **도로명('해돋이로' 등)·비업종 완벽 차단 필터(`isRoadOrNonBusinessName`, `isValidPlaceForCategory`)**, 전 세계 다국어 검색을 담당합니다. |
| **`route.js`** | 화면 지도 위 **경로선(Polyline) 표시**, 도보·대중교통 소요 시간 계산, 여행 코스 최적화, **구글·네이버·카카오 지도 연결 URL 생성**을 담당합니다. |
| **`app.js`** | 앱 초기화, **기기별 API 키 입력창 및 로컬 보안 저장/삭제**, Google 지도 로드, 내 위치(GPS) 감지, `❤️ 내 장소` 관리, 장소 카드 및 마커 렌더링을 담당합니다. |

## 🔐 안전한 API 키 사용 방법 (소스 코드 수정 불필요!)

1. **파일을 전혀 수정할 필요 없이** 아래 6개 파일(`index.html`, `style.css`, `config.js`, `search.js`, `route.js`, `app.js`)을 그대로 GitHub 저장소에 업로드합니다.
2. 스마트폰(아이폰 Safari)이나 컴퓨터에서 배포된 웹 주소에 처음 접속하면 **🔐 내 기기에 Google Maps API 키 저장** 입력창이 바로 나타납니다.
3. 여기에 API 키를 붙여넣고 **[🔒 이 기기에만 저장하고 시작하기]**를 누르면, 해당 폰이나 컴퓨터의 브라우저(`localStorage`)에만 키가 저장되며 두 번째 접속부터는 묻지 않고 즉시 지도가 열립니다.
4. 공용 PC 등에서 사용 후 키를 지우고 싶을 때는 우측 상단 **⚙️ 버튼 > [🗑️ 이 기기에서 API 키 삭제]**를 누르면 즉시 삭제됩니다.
