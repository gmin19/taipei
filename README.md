# 주변 여행 도우미 (다중 파일 분리 + 여행 발견 & 편의성 업그레이드 버전)

GitHub Pages와 같은 공개 저장소에 소스 코드를 올려도 **본인의 Google Maps API 키가 외부에 절대 노출되지 않도록**, 소스 코드 내 API 키는 비워두고 **각자의 스마트폰·컴퓨터 브라우저(`localStorage`)에만 안전하게 저장**되도록 설계된 다중 파일 버전입니다.

## ✨ 주요 업그레이드 기능 (5대 핵심 개선안 적용)

1. **🔥 리뷰 100+ 검증 토글 & 🏆 현지 인기순(베이지안 가중 평점) 정렬**:
   - 리뷰 1~2개짜리 5.0점 매장이 상단을 차지하는 문제를 방지하기 위해 **평점과 리뷰 신뢰도를 결합한 '🏆 현지 인기순'**을 기본 적용하고, 원탭 **'🔥 리뷰 100+'** 필터 버튼을 추가했습니다.
2. **✨ 여행발견(10종) vs 🛟 생활·편의(6종) 2그룹 카테고리 구조화**:
   - 상단 바에서 **[✨ 여행발견 | 🛟 생활·편의]**를 즉시 전환할 수 있으며, 여행지에 특화된 **🌙 야시장·야경, 🍺 로컬 바·펍, 🍨 디저트·빵, 🎁 소품·쇼핑, ♨️ 스파·마사지** 카테고리를 보강했습니다.
3. **➕ 주변 장소 10곳 더 보기 & 반경(600m / 1.5km / 3km) 선택**:
   - 상위 10곳에서 탐색이 끊기지 않고 하단의 **[➕ 주변 장소 10곳 더 보기]** 버튼으로 숨은 로컬 포인트를 최대 40~50곳까지 확장 탐색할 수 있습니다.
4. **🔍 기준점 주변 세부 메뉴·취향 키워드 검색 & 원탭 취향 칩**:
   - 숙소나 현재 위치를 기준점으로 유지한 채 **'우육면', '망고빙수', '루프탑', '이자카야'** 등 세부 키워드를 검색하는 **[🔍 주변검색]** 버튼과 카테고리별 **원탭 취향 태그칩**을 지원합니다.
5. **모바일 한 손 편의성 개선**:
   - **카드 UI 다이어트**: `🤍 내장소`와 `+ 코스`를 카드 우측 상단 아이콘으로 올리고 하단은 3개 핵심 버튼(`ℹ️ 상세·시간`, `🗺️ 경로보기`, `↗ 구글지도`)으로 단순화했습니다.
   - **스크롤-마커 자동 연동**: 하단 카드를 스크롤하면 지도 위 해당 마커가 실시간으로 커지며 강조됩니다.
   - **전 카드 예상 도보 시간·거리 기본 표시**: 7위 이후 카드에도 직선거리 기반 예상 도보 시간(`약 7분 · 직선 420m`)을 즉시 표시합니다.
   - **🗓️ Day 1~3 일자별 코스 탭 & 장소별 메모 & 🕒 시간·업종 맞춤 동선 정렬**: 오전 명소 → 점심 맛집 → 오후 카페 → 저녁 식사 → 야경/바 순서의 스마트 코스 정렬과 한 줄 메모를 지원합니다.

## 📁 파일 구성 및 역할

| 파일명 | 역할 및 주요 내용 |
| :--- | :--- |
| **`index.html`** | 웹앱의 화면 뼈대(HTML 마크업)와 스타일·스크립트 연결만 담당합니다. |
| **`style.css`** | 아이폰 Safari 노치 대응, 상단 플로팅 바, 하단 시트, 장소 카드, 모달 등 모든 디자인 스타일을 담당합니다. |
| **`config.js`** | 2그룹 카테고리 정의, 취향 칩, 베이지안 인기도 계산, 전역 상태(`state`) 및 공통 유틸리티 함수를 담당합니다. |
| **`search.js`** | 주변 카테고리 검색, 세부 메뉴·취향 키워드 검색, `+10곳 더보기` 확장 탐색, 도로명 차단 필터 및 Google 평점 매칭을 담당합니다. |
| **`route.js`** | 화면 지도 위 경로선(Polyline) 표시, 도보·대중교통 소요 시간 계산, Day 1~3 여행 코스·메모 및 스마트 동선 최적화를 담당합니다. |
| **`app.js`** | 앱 초기화, 기기별 API 키 입력창 및 로컬 보안 저장/삭제, Google 지도 로드, `❤️ 내 장소` 관리, 다이어트 카드 및 스크롤-마커 연동을 담당합니다. |
