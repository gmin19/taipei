⚙️ API 키 설정 및 Places API (New) 안내

🚨 권한 오류 발생 시 확인사항 (Places API (New) 전용)

이 앱은 구형 Places API 없이 최신 Places API (New)와 Routes API만 사용합니다.

  1. API 및 서비스 > 라이브러리에서 Maps JavaScript API, Places API (New), Routes API 3개가 사용(Enable) 상태인지 확인하세요.
  2. 사용자 인증 정보 > API 키 클릭 > API 제한사항에서 '키 제한'을 선택하신 경우, 허용 목록 드롭다운에서 Maps JavaScript API, Places API (New), Routes API 3개가 모두 체크되어 있는지 확인 후 [저장]을 눌러주세요.

1. 브라우저 임시 API 키 입력 (빠른 테스트용)

기본적으로는 index.html 상단의 GOOGLE_MAPS_API_KEY 상수를 수정해 사용합니다. 지금 바로 브라우저에서 테스트하려면 아래에 API 키를 입력해 적용할 수 있습니다.

2. 아이폰(iPhone Safari)에서 실행하는 방법

  1. 중요 (HTTPS 필수): 아이폰에서 file:// 로컬 파일로 직접 열면 iOS 보안 정책상 위치 권한(Geolocation)과 Google Maps API가 작동하지 않을 수 있습니다.
  2. GitHub Pages 무료 호스팅 방법:
    • GitHub에 새 저장소(Repository)를 만들고 이 index.html 파일 하나만 업로드합니다.
    • 저장소의 Settings > Pages 메뉴에서 Branch를 main으로 선택해 저장합니다.
    • 생성된 https://<아이디>.github.io/<저장소명>/ 주소를 아이폰 Safari에서 열고 공유 > 홈 화면에 추가를 누르면 앱처럼 편리하게 사용할 수 있습니다.
